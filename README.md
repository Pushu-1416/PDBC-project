# Customer Churn Analysis using Python PDBC

## Project Overview

This project analyzes customer churn data using **Python, MySQL, and PDBC (Python Database Connectivity)**.

The project connects Python with a MySQL database, retrieves customer data, performs churn analysis, and generates useful business insights.

## Technologies Used

* Python
* MySQL
* PDBC
* mysql-connector-python

## Dataset

The project uses the **Telco Customer Churn Dataset**.

The dataset contains customer information such as:

* Customer ID
* Gender
* Senior Citizen
* Tenure
* Contract
* Internet Service
* Payment Method
* Monthly Charges
* Total Charges
* Churn

## Project Features

* Connect Python with MySQL using PDBC
* Retrieve customer data from MySQL
* Count churned and non-churned customers
* Calculate churn rate
* Analyze churn by gender
* Analyze churn by contract type
* Analyze churn by internet service
* Analyze churn by payment method
* Analyze churn by senior citizen status
* Analyze churn by tenure
* Analyze monthly charges
* Analyze total charges
* Generate business insights
* Handle database exceptions
* Test the complete project
